# G1 v4 HF 격자 시험 L1·L2 (집 PC, 2026-10-24)

G1 v4 반쪽 모델, grid2 격자 계열, simpleFoam k-ω SST, U = 50 m/s, 2000회. OpenFOAM v2512, i5-12400F 6코어(WSL2, np 6).
힘은 전체 차량 기준이고, 마지막 1000회 평균에 자기상관 보정 표준오차를 붙였다(`grid_study.case_result`).
형상은 `e4ab33b`의 `build_car.py --half --fia`(zmode, 코너 모드)와 `--fw-flap-delta -10 --rw-flap-delta -25`(xmode, 직선 모드)이고, `source.dirty`는 false다.
자동 생성 표는 [grid_study.md](grid_study.md), 그림은 [grid_study.png](grid_study.png)에 있다.

**주의:** 회사 PC가 10-24에 `ground_to_car` 오류를 고쳐 G1 v5를 만들었다. v5는 서스펜션 STL 2개만 다르다. 이 시험은 고치기 전 서스펜션(v4)을 쓴다.

## 전체 차량

| 모드 | 단계 | 셀 | CL·A [m²] | CD·A [m²] | 앞날개 CL·A | 차체 CL·A | 뒷날개 CL·A |
|---|---|---|---|---|---|---|---|
| zmode | L1 | 1,286,706 | 1.307 ± 0.006 | 0.993 ± 0.002 | 0.891 | 0.138 | 0.652 |
| zmode | L2 | 2,390,309 | 1.560 ± 0.005 | 1.004 ± 0.001 | 0.915 | 0.198 | 0.738 |
| | L1 → L2 | | **+0.253 (+19.4 %)** | +0.011 (+1.1 %) | +0.024 | +0.060 | +0.086 |
| xmode | L1 | 1,289,059 | 0.771 ± 0.004 | 0.831 ± 0.001 | 0.536 | 0.228 | 0.304 |
| xmode | L2 | 2,392,757 | 1.001 ± 0.009 | 0.827 ± 0.002 | 0.559 | 0.342 | 0.304 |
| | L1 → L2 | | **+0.230 (+29.8 %)** | −0.004 (−0.5 %) | +0.023 | +0.114 | 0.000 |

- **CL·A는 L1 → L2에서 20~30 % 커졌다.** 변화가 통계 오차(0.01 이하)보다 20배 이상 크므로 격자가 아직 수렴하지 않은 것이다. HF 기준 ±2 %에서 멀다.
- CD·A는 L1 → L2 변화가 zmode +1.1 %, xmode −0.5 %로 이미 기준(±2.5 %, ±4 %) 안이다.
- 두 단계만으로는 수렴 차수와 외삽값을 구할 수 없다(Richardson은 세 단계 필요). HF 판정은 L3가 끝나야 한다.
- 집 PC L1 zmode(1.307 / 0.993)는 회사 `g1v4_grid2_L1`(1.310 / 0.996)과 통계 오차 안에서 같다.

## 부품별 L1 → L2 변화 (마지막 400회 평균, `cfd_report.py`)

| 부품 | zmode CL·A | zmode CD·A | xmode CL·A | xmode CD·A |
|---|---|---|---|---|
| 앞날개 | 0.883 → 0.915 | 0.108 → 0.112 | 0.539 → 0.557 | 0.058 → 0.060 |
| 차체 | 0.140 → 0.192 | 0.251 → 0.264 | 0.226 → 0.337 | 0.250 → 0.238 |
| 뒷날개 | 0.651 → 0.738 | 0.145 → 0.153 | 0.303 → 0.304 | 0.042 → 0.044 |
| 바퀴 | −0.373 → −0.318 | 0.357 → 0.346 | −0.298 → −0.247 | 0.337 → 0.353 |
| 서스펜션 | −0.052 → −0.018 | 0.063 → 0.057 | −0.045 → −0.025 | 0.067 → 0.057 |
| Floor Board | 0.097 → 0.096 | 0.032 → 0.030 | 0.084 → 0.117 | 0.039 → 0.033 |
| 나머지(헤일로, 헬멧, 미러) | −0.045 → −0.055 | 0.038 → 0.043 | −0.043 → −0.056 | 0.039 → 0.042 |
| 전체 | 1.301 → 1.548 | 0.994 → 1.004 | 0.767 → 0.988 | 0.831 → 0.827 |

- CL·A 증가는 바닥(차체), 바퀴, 서스펜션에서 주로 나온다. 바닥 아래 흐름과 바퀴 후류가 격자에 민감하다는 뜻이다.
- zmode 뒷날개는 +0.087이지만 xmode(플랩을 연 상태) 뒷날개는 변하지 않았다. 플랩을 세운 상태의 흐름(플랩 앞전 흡입, 날개 사이 틈)이 격자에 민감한 것으로 보인다(확인 안 함).
- 프리즘 층: L1 2.0~2.5층, L2 2.4~2.7층(목표 3층). 차체 평균 y+는 100 → 70이다.

## 두 모드의 차이 (LF 판정)

| 단계 | ΔCL·A (x − z) | ΔCD·A (x − z) | L2 대비 ΔCL·A | L2 대비 ΔCD·A |
|---|---|---|---|---|
| L1 | −0.536 | −0.162 | +4.2 % | +8.5 % |
| L2 | −0.559 | −0.177 | 0 | 0 |

- 절대값은 20~30 % 틀려도 **두 설계의 차이는 L1이 L2의 10 % 안에서 따라간다**(LF 기준 ±10 %). CD·A는 8.5 %로 한계에 가깝다.
- 기준이 L2라서 잠정 판정이다. L3로 다시 판정한다.

## 계산 비용 (i5-12400F, np 6)

| 케이스 | 메싱 [분] | simpleFoam [분] | s/회 | 최대 추가 메모리 [GB] |

| xmode L1 | 5.0 | 63.4 | 1.88 | 3.5 (snappyHexMesh) |

- 비용 상수는 1M 셀·1회당 7.6~9.2 코어·초다. 회사 계획의 추정(설계당 L1 0.7 h, L2 1.9 h)과 비슷하다.
- L1 → L2 셀은 1.86배, 메모리는 1.6배다. **L3(약 450만 셀) 추정은 메모리 약 10 GB, 케이스당 약 3.5~4 h**다. WSL 기본 한도 15 GB 안에 들어 `.wslconfig` 변경 없이 돌릴 수 있을 것으로 본다.
- L4(약 800만 셀)는 메모리 약 15 GB, 케이스당 약 6.5 h로 추정한다. 두 모드면 13 h를 넘으므로 집 PC에서는 현실적이지 않다.
